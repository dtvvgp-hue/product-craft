# Merge notes

This package consolidates the useful behavioral guidance from the supplied collections:

- UI/UX taste, anti-slop, visual systems, motion, branding, redesign, and image-to-code patterns.
- React, web interface, composition, performance, deployment, and mobile engineering guidance.
- Planning, review, QA, debugging, release, and agent swarm patterns.
- Safety and evidence practices from the workflow-oriented material.

The original archives also contain complete repositories, generated registries, duplicated skill copies, test fixtures, provider-specific CLIs, installation scripts, and environment-specific workflows. Those were not copied into this portable skill because they would make loading slower, create conflicts, or pretend unavailable tools exist.
