# Unified Product Engineering

A consolidated, portable skill for turning product requests into polished, tested, shippable web or mobile work.

## Included

- Product framing and repository reconnaissance
- Premium UI/UX direction and anti-slop review
- React, TypeScript, Next.js, and performance guidance
- React Native and Expo guidance
- Debugging, QA, accessibility, and evidence-based review
- Agent decomposition and parallel workflow
- Release readiness and rollback thinking

The package intentionally excludes vendor-specific credentials, destructive automation, duplicated generated assets, full source repositories, and environment-bound CLI integrations. It is designed to be loaded as one skill with progressive-disclosure references.
